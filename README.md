# CLI Weather App
 
Get the current weather for any city, right from your terminal.
 
```
$ python3 weather.py Boston
 
Weather in Boston
Temperature: 3.7°C
Wind speed: 4.6 km/h
```
 
## Setup
 
```bash
pip3 install requests
```
 
## Usage
 
```bash
python3 weather.py <city>
```
 
## Built With
 
- Python
- [Open-Meteo API](https://open-meteo.com/)
